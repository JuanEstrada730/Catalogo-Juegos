# Catálogo de Videojuegos

Aplicación web hecha con React para explorar un catálogo de videojuegos,
buscar por nombre, filtrar por género, marcar favoritos y ver el detalle
de cada juego.

## Autor
Juan David Estrada Piñeros

## Funcionalidades
- Catálogo de 9 videojuegos en tarjetas
- Búsqueda por nombre en tiempo real
- Filtro por género (funciona junto con la búsqueda)
- Favoritos con contador y vista de solo favoritos
- Detalle del videojuego en un modal

## Tecnologías
- React (componentes funcionales y JSX)
- Vite
- Hooks: useState

## Requisitos previos
- Node.js 18 o superior

## Instrucciones de ejecución
1. Clonar o descargar el proyecto
2. Abrir una terminal en la carpeta del proyecto
3. Instalar dependencias:
   npm install
4. Iniciar el servidor de desarrollo:
   npm run dev
5. Abrir en el navegador la URL que aparece en la terminal
   (normalmente http://localhost:5173)
